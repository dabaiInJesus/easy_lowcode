## 样式类使用说明

### dialog-content (500px)
适用于中等复杂度的表单：
- 注册外部接口
- 注册表资源

### dialog-content-lg (600px)
适用于复杂配置、多选项卡：
- 生成API配置

### dialog-content-sm (400px)
适用于简单表单：
- 目前未使用，预留

### 全局默认
适用于内容较少的简单弹框：
- 大部分系统管理的增删改查弹框
- 确认对话框
- 简单表单

## 优化效果

### 优化前
❌ 弹框内容过多时，整个页面出现滚动条  
❌ 不同弹框高度不一致  
❌ 需要手动设置每个弹框的样式  

### 优化后
✅ 页面永远没有滚动条  
✅ 弹框内部滚动，体验更好  
✅ 统一的高度限制  
✅ 开箱即用，无需配置  

## 技术实现

### 核心CSS
```css
/* 防止弹框打开时页面出现滚动条 */
.el-overlay {
  overflow: hidden !important;
}

/* 弹框主体最大高度限制 */
.el-dialog__body {
  max-height: calc(100vh - 200px);
  overflow-y: auto;
  padding-right: 10px;
}

/* 小屏幕适配 */
@media (max-width: 768px) {
  .el-dialog__body {
    max-height: calc(100vh - 150px);
  }
}
```

### 预定义样式类
```css
.dialog-content      /* max-height: 500px */
.dialog-content-lg   /* max-height: 600px */
.dialog-content-sm   /* max-height: 400px */
```

## 维护建议

1. **新增弹框时**：
   - 优先使用全局默认样式
   - 内容较多时使用 `dialog-content` 或 `dialog-content-lg`
   - 避免在组件内重复定义 `.dialog-content` 等样式

2. **修改弹框时**：
   - 如需调整高度，使用预定义的样式类
   - 不要直接修改全局样式，除非确实需要

3. **测试要点**：
   - 弹框打开时页面无滚动条
   - 内容超出时弹框内部可滚动
   - 移动端显示正常
