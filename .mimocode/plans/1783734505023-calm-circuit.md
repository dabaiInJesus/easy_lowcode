# 登录403问题修复方案

## 根因

`AuthController.java` 第32行有类级别 `@PreAuthorize("isAuthenticated()")`。

Spring Security 的 `@EnableMethodSecurity` 将类级别和方法级别的 `@PreAuthorize` 以 AND 逻辑组合：
- 类级别：`isAuthenticated()` — 要求已认证
- 方法级别：`permitAll()` — 允许匿名
- 实际生效：`isAuthenticated() AND permitAll()` = `isAuthenticated()` → 未登录请求被拦截

HTTP Security 的 `permitAll()` 放行了 URL，但 Method Security 在 Controller 方法级别再次拦截，抛出 `AccessDeniedException`。

## 修复方案

### 1. 移除 AuthController 类级别 @PreAuthorize

**文件**: `easy-lowcode-auth/src/main/java/com/dabai/easy_lowcode/auth/controller/AuthController.java`

```java
// 修改前（第32行）
@PreAuthorize("isAuthenticated()")
public class AuthController {

// 修改后：移除类级别注解
public class AuthController {
```

移除后：
- `login()` 方法的 `@PreAuthorize("permitAll()")` 单独生效
- 其他方法（getCurrentUser等）由 HTTP Security 的 `anyRequest().authenticated()` 兜底
- 有具体 `@PreAuthorize` 注解的方法（如 `hasRole('admin')`）继续生效

### 2. 补全 CORS 白名单（次要）

**文件**: `easy-lowcode-auth/src/main/java/com/dabai/easy_lowcode/auth/config/SecurityConfig.java`

默认 CORS 白名单缺少 `localhost:6173`（Vite dev server 端口）：

```java
// 修改前
"http://localhost:5173,http://localhost:8081"

// 修改后
"http://localhost:5173,http://localhost:6173,http://localhost:8081"
```

### 1.1 P0-2：SQL SELECT-only 校验

**目标**：防止用户提交的 SQL 执行非 SELECT 语句（DROP、DELETE、UPDATE 等）。

**Step 1：创建 SqlValidator 工具类**

- 文件：`easy-lowcode-common/src/main/java/com/dabai/easy_lowcode/common/sql/SqlValidator.java`（新建）
- 依赖：JSqlParser 4.6（已在父 pom.xml 中声明）

```java
package com.dabai.easy_lowcode.common.sql;

import net.sf.jsqlparser.JSQLParserException;
import net.sf.jsqlparser.parser.CCJSqlParserUtil;
import net.sf.jsqlparser.statement.Statement;
import net.sf.jsqlparser.statement.select.Select;

public final class SqlValidator {

    private static final String[] DANGEROUS_KEYWORDS = {
        ";", "--", "xp_cmdshell", "EXEC", "EXECUTE", "CALL"
    };

    private SqlValidator() {}

    /**
     * 校验 SQL 仅允许 SELECT 语句
     */
    public static void assertSelectOnly(String sql) {
        if (sql == null || sql.trim().isEmpty()) {
            throw new IllegalArgumentException("SQL 不能为空");
        }
        String trimmed = sql.trim();
        // 拒绝多语句（分号）
        if (trimmed.contains(";")) {
            throw new IllegalArgumentException("不允许执行多条 SQL 语句");
        }
        // 拒绝 SQL 注释
        if (trimmed.contains("--") || trimmed.contains("/*")) {
            throw new IllegalArgumentException("不允许包含 SQL 注释");
        }
        try {
            Statement stmt = CCJSqlParserUtil.parse(trimmed);
            if (!(stmt instanceof Select)) {
                throw new IllegalArgumentException("仅允许 SELECT 语句");
            }
        } catch (JSQLParserException e) {
            throw new IllegalArgumentException("SQL 解析失败: " + e.getMessage());
        }
    }
}
```

### 2.2 P1-2：引入 HikariCP 连接池

- 文件：`easy-lowcode-collector/src/main/java/com/dabai/easy_lowcode/collector/service/impl/DataSourceProviderImpl.java`
- 修改：
  - 新增 `Map<Long, HikariDataSource> pool = new ConcurrentHashMap<>()`
  - `getConnection()` 改为从池中获取
  - 新增 `evictPool(Long id)` 方法用于数据源配置更新时清除缓存
  - pom.xml 添加 HikariCP 依赖（Spring Boot 已自带）

```java
private final ConcurrentHashMap<Long, HikariDataSource> pool = new ConcurrentHashMap<>();

public Connection getConnection(DataSourceInfo info) throws Exception {
    HikariDataSource ds = pool.computeIfAbsent(info.getId(), id -> {
        HikariConfig config = new HikariConfig();
        config.setJdbcUrl(info.getUrl());
        config.setUsername(info.getUsername());
        config.setPassword(decryptPassword(info.getPassword()));
        config.setDriverClassName(info.getDriverClassName());
        config.setMaximumPoolSize(10);
        config.setIdleTimeout(300_000); // 5 min
        config.setConnectionTimeout(10_000);
        return new HikariDataSource(config);
    });
    return ds.getConnection();
}

public void evictPool(Long id) {
    HikariDataSource ds = pool.remove(id);
    if (ds != null) ds.close();
}
```

**验证**：观察高频查询场景下连接建立耗时下降。

```java
@DeleteMapping("/batch")
@PreAuthorize("hasRole('admin')")
public Result<Void> batchDelete(@RequestBody List<Long> ids) {
    if (ids == null || ids.isEmpty()) return Result.error("请选择要删除的资源");
    if (ids.size() > 50) return Result.error("单次最多删除 50 条");
    List<Long> relatedIds = ids.stream()
        .filter(id -> tableResourceService.hasRelatedApi(id))
        .collect(Collectors.toList());
    if (!relatedIds.isEmpty()) {
        return Result.error("所选资源中包含已注册 API 的资源，无法删除");
    }
    tableResourceService.removeBatchByIds(ids);
    return Result.success("批量删除成功");
}
```
