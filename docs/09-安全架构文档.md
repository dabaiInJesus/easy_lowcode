## 二、认证流程

### 2.1 JWT 认证

```
1. 用户登录 → POST /api/auth/login
2. 验证用户名密码 → BCrypt 校验
3. 生成 JWT Token → 包含 userId, username, roles
4. 返回 Token → 前端存储在 sessionStorage
5. 后续请求 → Header: Authorization: Bearer {token}
6. JWT 验证 → JwtAuthenticationFilter 解析 Token
7. 设置安全上下文 → SecurityContextHolder
```

### 2.2 Token 配置

| 配置项 | 值 | 说明 |
|--------|-----|------|
| 签名算法 | HS256 | HMAC-SHA256 |
| 过期时间 | 24小时 | 可配置 |
| 密钥来源 | 环境变量 JWT_SECRET | 禁止硬编码 |
| 存储位置 | sessionStorage | 避免 XSS 窃取 |

### 2.3 Token 黑名单

- 登出时将 Token 加入 Redis 黑名单
- 黑名单 Key 格式：`token:blacklist:{tokenId}`
- 过期时间与 Token 过期时间一致

## 三、授权模型

### 3.1 RBAC 权限模型

```
用户 (User)
  │
  ├── 角色 (Role)
  │     │
  │     └── 菜单/权限 (Menu)
  │           │
  │           └── 按钮权限 (Button)
  │
  └── 部门 (Dept)
        │
        └── 数据权限 (Data Scope)
```

### 3.2 权限标识格式

```
{模块}:{资源}:{操作}
```

示例：
- `system:user:list` - 查看用户列表
- `system:user:create` - 创建用户
- `system:role:assign` - 分配角色
- `resource:query:single` - 单资源查询

### 3.3 权限校验

```java
// Controller 方法级别
@PreAuthorize("hasRole('admin')")
@PreAuthorize("hasAuthority('system:user:list')")
public Result<List<SysUser>> getUserList() { ... }
```

## 四、数据加密

### 4.1 密码加密

| 算法 | 说明 |
|------|------|
| BCrypt | 密码哈希 |
| 盐值 | 自动生成 |
| 强度 | 10轮 |

```java
// 加密
String hashed = BCrypt.hashpw(password, BCrypt.gensalt(10));

// 验证
boolean match = BCrypt.checkpw(password, hashed);
```

### 4.2 敏感数据加密

| 数据 | 算法 | 密钥来源 |
|------|------|---------|
| 数据库密码 | AES-GCM | ENCRYPT_AES_KEY |
| AI API Key | AES-GCM | ENCRYPT_AES_KEY |
| JWT Secret | HMAC-SHA256 | JWT_SECRET |

### 4.3 AES 加密配置

| 配置项 | 值 |
|--------|-----|
| 算法 | AES/GCM/NoPadding |
| 密钥长度 | 128/192/256位 |
| Nonce | 随机生成（每次加密） |
| 密钥来源 | 环境变量 ENCRYPT_AES_KEY |

## 五、安全配置

### 5.1 CORS 配置

```yaml
spring:
  security:
    cors:
      allowed-origins: ${CORS_ORIGINS:*}
      allowed-methods: GET,POST,PUT,DELETE,OPTIONS
      allowed-headers: *
      allow-credentials: true
      max-age: 3600
```

### 5.2 SQL 注入防护

| 防护层 | 说明 |
|--------|------|
| 参数绑定 | MyBatis Plus #{param} |
| 关键词黑名单 | SELECT/INSERT/UPDATE/DELETE 等 |
| 列白名单 | configJson 中定义的字段 |
| 表名校验 | 正则表达式校验 |

### 5.3 XSS 防护

- Vue 模板自动转义 HTML
- 富文本内容使用 DOMPurify 过滤
- 输出编码

### 5.4 CSRF 防护

- JWT Token 不使用 Cookie
- SameSite=Strict
- 自定义 Header 校验
