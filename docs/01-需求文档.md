# Easy Lowcode — 需求文档

> 版本：1.0.0-SNAPSHOT
> 最后更新：2026-07-08

## 1. 项目概述

### 1.1 产品定位

Easy Lowcode 是一个面向开发者和数据分析师的开源低代码开发平台，目标是通过可视化配置和高度可扩展的插件体系，将重复性的 CRUD 开发、数据查询、数据采集、可视化大屏等工作量降低 80% 以上。

### 1.2 核心价值

- **配置驱动**：基于 JSON 配置体系（configJson），无需写代码即可完成数据查询、参数处理、结果加工、展示配置
- **处理器插件化**：参数处理器和结果处理器均可按需插拔，内置 7+ 常用处理器，支持自定义扩展
- **多源融合**：统一数据源管理（MySQL/PostgreSQL/Oracle/SQLServer），跨资源统一查询
- **AI 增强**：集成 Text-to-SQL、图表推荐、AI 对话 Agent，降低数据分析门槛
- **搜索引擎**：默认 Meilisearch 轻量全文搜索，可选 Elasticsearch

### 1.3 目标用户

| 角色 | 典型技能 | 核心场景 |
|------|---------|---------|
| **系统管理员** | 运维 | 用户/角色/权限管理、菜单配置、系统监控 |
| **开发者** | Java/TypeScript | 数据源注册、资源配置（处理器/模板）、API 注册 |
| **数据分析师** | SQL | 资源查询、统一Key搜索、数据分析、大屏设计 |
| **查看者** | 无 | 查看已发布的大屏、执行已授权的查询 |

### 1.4 核心术语

| 术语 | 说明 |
|------|------|
| **资源 (Resource)** | 一个可查询的数据单元，对应一张数据库表或一个 API 端点 |
| **configJson** | 资源配置的核心 JSON，描述字段定义、处理器链、查询模板、展示设置 |
| **参数处理器** | 在 SQL 执行前对用户输入做转换/校验/填充 |
| **结果处理器** | 在 SQL 执行后对结果集做脱敏/映射/格式化 |
| **查询模板** | 带 `{{placeholder}}` 占位符的 SQL 模板，支持条件判断 |
| **统一Key** | 跨资源映射字段，用于多资源精确关联查询 |
| **全文检索** | 基于 Meilisearch/ES 的文档内容搜索，支持 PDF/Word/Excel/TXT |

## 3. 非功能需求

### 3.1 性能

| 指标 | 目标 |
|------|------|
| 页面加载 | 首屏 < 2s |
| 数据查询 | 简单查询 < 500ms，复杂查询 < 3s |
| 全文搜索 | < 1s（基于 Meilisearch） |
| 并发用户 | 支持 100+ 并发 |

### 3.2 安全

| 要求 | 说明 |
|------|------|
| 认证方式 | JWT Token，Bearer 模式 |
| Token 管理 | Redis 黑名单机制，支持登出即失效 |
| 密码存储 | BCrypt 加密，禁止明文日志 |
| 权限模型 | RBAC（角色-菜单-按钮）+ 数据权限 |
| SQL 注入防护 | 关键词黑名单 + 列白名单双重校验 |
| 敏感数据加密 | AES 加密存储（手机号、身份证等） |
| Long ID 精度 | `@JsonSerialize(ToStringSerializer.class)` 防止前端精度丢失 |

### 3.3 可用性

| 要求 | 说明 |
|------|------|
| 部署方式 | 单体模式（startup）和微服务模式（gateway）双模式 |
| 数据库迁移 | Liquibase 自动管理 DDL/DML |
| 服务依赖 | PostgreSQL + Redis + RocketMQ + Meilisearch |
| 错误处理 | 全局异常拦截，统一返回 `Result<T>` |

### 3.4 可扩展性

| 维度 | 说明 |
|------|------|
| 处理器扩展 | 实现 `Processor<T>` 接口，注册到 `ProcessorRegistry` |
| 数据源扩展 | 添加 JDBC 驱动和方言适配 |
| 搜索引擎扩展 | 实现 `SearchService` 接口 |
| 存储后端扩展 | 实现 `StorageService` 接口 |
| AI Provider 扩展 | 添加 Spring AI 的实现依赖和配置 |
