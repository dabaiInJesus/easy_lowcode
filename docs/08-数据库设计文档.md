## 一、数据库概述

### 1.1 数据库选型

| 特性 | 说明 |
|------|------|
| 数据库 | PostgreSQL 17 |
| 字符集 | UTF-8 |
| 排序规则 | zh_CN.UTF-8 |
| 连接池 | HikariCP |

### 1.2 模块划分

| 模块 | 表前缀 | 说明 |

## 三、数据字典

### 3.1 状态字段

| 字段 | 值 | 说明 |
|------|-----|------|
| status | 0 | 禁用/禁用 |
| status | 1 | 启用/正常 |
| deleted | 0 | 未删除 |
| deleted | 1 | 已删除 |

### 3.2 菜单类型

| 值 | 说明 |
|----|------|
| 1 | 目录 |
| 2 | 菜单 |
| 3 | 按钮 |

### 3.3 ETL 流程状态

| 值 | 说明 |
|----|------|
| DRAFT | 草稿 |
| RUNNING | 运行中 |
| COMPLETED | 已完成 |
| FAILED | 失败 |

### 3.4 ETL 调度方式

| 值 | 说明 |
|----|------|
| MANUAL | 手动 |
| CRON | CRON表达式 |

## 四、索引设计

### 4.1 主键索引

所有表的 `id` 字段为主键，使用雪花算法生成。

### 4.2 唯一索引

| 表名 | 字段 | 索引名 |
|------|------|--------|
| sys_user | username | uk_sys_user_username |
| sys_role | role_code | uk_sys_role_code |
| data_source_config | code | uk_data_source_code |
| table_resource | resource_code | uk_table_resource_code |
| table_resource | api_path | uk_table_resource_api_path |
| etl_flow | flow_code | uk_etl_flow_code |
| ai_agent | agent_code | uk_ai_agent_code |

### 4.3 普通索引

| 表名 | 字段 | 索引名 | 说明 |
|------|------|--------|------|
| sys_user | dept_id | idx_sys_user_dept | 部门查询 |
| sys_menu | parent_id | idx_sys_menu_parent | 父菜单查询 |
| sys_dept | parent_id | idx_sys_dept_parent | 父部门查询 |
| table_resource | datasource_id | idx_table_resource_ds | 数据源查询 |
| etl_flow_execution | flow_id | idx_flow_exec_flow | 流程执行查询 |
| etl_flow_execution | exec_status | idx_flow_exec_status | 状态查询 |
